1. Go to https://github.com/new
2. Name: `simple_ai_chatbot`
3. Description: `An intelligent Python learning chatbot`
4. Make it Public
5. Click "Create repository"
6. **Copy the HTTPS URL** shown on the next screen

### Step 2: Push Your Code
```bash
cd d:\Farhan_courses\decodelab_intership\project_01
git init
git add .
git commit -m "Initial commit: PyGuide AI chatbot project"
git remote add origin https://github.com/YOUR_USERNAME/simple_ai_chatbot.git
git branch -M main
git push -u origin main
```

### Step 3: Verify
Go to https://github.com/YOUR_USERNAME/simple_ai_chatbot
Your project should be visible!

## 🆘 Troubleshooting

**"streamlit not found"**
```bash
pip install streamlit
```

**"intents.json not found"**
Make sure you're running from the correct directory

**"git: command not found"**
Install Git from https://git-scm.com/

**GitHub push fails**
- Check your internet connection
- Verify GitHub username and token
- Use personal access token (not password)
