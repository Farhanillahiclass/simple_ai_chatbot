# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-08-12

### Added
- Initial release of PyGuide AI
- 20+ Python learning topics with definitions, examples, and code snippets
- Dual interface (CLI and Web/Streamlit)
- Smart topic matching algorithm with multiple matching strategies
- Professional documentation with comprehensive README
- MIT License for open-source distribution
- Type hints and docstrings for all functions
- Knowledge base stored in JSON format
- Chat history feature in web interface
- Topics explorer sidebar in web application
- Comprehensive error handling and user feedback
- UTF-8 encoding support for internationalization
- Professional project structure ready for GitHub
- Contributing guidelines and code of conduct

### Features
- **CLI Interface** (`main.py`):
  - Command-line chatbot for quick access
  - Professional ASCII dashboard
  - Menu system for topic exploration
  - Command support (menu, clear, exit)
  - Real-time response generation

- **Web Interface** (`app.py`):
  - Streamlit-based web application
  - Interactive chat interface
  - Topics explorer sidebar
  - Chat history preservation
  - Responsive design
  - Code syntax highlighting
  - Professional styling with custom CSS

- **Knowledge Base** (`intents.json`):
  - Variables and Data Types
  - Collections (List, Tuple, Dictionary, Set)
  - Control Flow (If Statements, Loops)
  - Functions and Advanced Functions
  - Object-Oriented Programming
  - Exception Handling
  - File I/O and JSON
  - List Comprehensions
  - Generators and Decorators
  - String and List Methods
  - And many more...

### Technologies
- Python 3.7+
- Streamlit for web interface
- JSON for data storage
- Type hints for code quality
- Professional documentation practices

### Documentation
- Comprehensive README.md with setup instructions
- Contributing guidelines (CONTRIBUTING.md)
- MIT License
- Code comments and docstrings throughout
- Example usage in both CLI and web formats
