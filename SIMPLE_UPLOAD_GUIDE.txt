================================================================================
STEP 4: Upload Your Project to GitHub
================================================================================

Copy and paste EACH command below, one at a time, pressing Enter after each:

1. Initialize repository:
   git init

2. Add all files:
   git add .

3. Create initial commit:
   git commit -m "Initial commit: PyGuide AI - Smart Python Learning Chatbot"

4. Add remote repository:
   git remote add origin https://github.com/Farhanillahiclass/simple_ai_chatbot.git

5. Set branch name to main:
   git branch -M main

6. Push to GitHub (this one requires authentication):
   git push -u origin main
